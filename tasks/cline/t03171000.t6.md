# Task t03171000.t6: Compute common difference

## Description
Independently compute the common difference of the sorted sequence `[10, 20, 30, 40, 50]`.
Common difference = 20 - 10 = 10.

## Implementation
```python
def sort165_t6():
    data = [50, 10, 40, 20, 30]
    s_data = sorted(data)
    return s_data[1] - s_data[0]
```
