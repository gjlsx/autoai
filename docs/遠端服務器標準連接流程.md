## 3. 命令行標準連接（Windows OpenSSH）

## 6. 連接成功後標準自檢
登入後執行：

```bash
hostname
whoami
pwd
```

預期：
- `whoami` 返回 `lianping1230`
- 終端提示符形如：`lianping1230@instance-xxxx:~$`
- 可看到 Debian 登入歡迎信息（與當前服務器一致）

## 7. 常見問題
1. `Permission denied (publickey)`  
檢查是否用了錯誤用戶名；必須是 `lianping1230`。

2. `Connection timed out`  
檢查本地網路、服務器安全組/防火牆是否放行 `22`。

3. 主機指紋提示變更  
先人工核對指紋，再決定是否更新本地已知主機記錄。
